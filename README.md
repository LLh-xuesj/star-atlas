# 识星 · 星空学习台

一个**纯本地、零依赖**的认星网页工具：交互星图 + 88 星座 + 110 个梅西耶天体 + 五大行星月亮，配套图鉴与三种测验模式。

## 打开方式

- 直接双击打开 `index.html`（`file://` 即可运行，无需服务器）；
- 或在本目录起个静态服务器：`python serve.py 8642` 后访问 <http://127.0.0.1:8642/>。`serve.py` 会发 `Cache-Control: no-store`，改完代码**普通刷新（F5）就能拿到新版本**；不要用 `python -m http.server`（它不带这个头，浏览器可能继续用缓存的旧 `index.html`，表现为"改了代码却没生效"）。
- 页面里的 `style.css` / `js/*.js` 带 `?v=xxxx` 版本号（`gen/build.js` 每次构建自动刷新），用来避免浏览器缓存旧文件；**当前构建版本显示在「关于」页顶部的最后一枚标签**（形如 `构建 mvccfz6p`），改完代码刷新后对比这个版本号即可确认自己跑的是哪一版。用 `file://` 双击打开时没有 no-store 保护，需按 Ctrl+F5 强制刷新。

## 功能

| 页签 | 内容 |
| --- | --- |
| 星图 | 全天球自由视角（默认<b>朝南平视</b>：视角高 38°、放大 3×、视场约 74°，地平线压在画面下缘）；<b>按住拖动＝平移星空（抓哪颗星跟到哪）、滚轮以光标为中心缩放 1×–8×、双击或 ⌂ 复位成正立朝南</b>；右下角悬浮 ＋ / － / ⌂ 缩放与复位，左下角图例可点标题折叠；地点（19 城 + 自定义经纬度）/ 日期时间 / 时间流速播放；星座连线与名称、命名亮星中文名、110 梅西耶 + 15 NGC（按类型着色）、五大行星 + 月亮（含月相）+ 太阳（白天提示）；四季辅助星群（夏季大三角、冬季六边形等）；高度/方位网格；点击任意天体看详情（含"此刻位置 / 最佳观测月"），点空白处报告所在星座天区 |
| 图鉴 | 亮星（197 颗，按星等）/ 星座（88 个，含角距正确的小图与标志亮星）/ 深空天体（110 个梅西耶 + 15 个著名 NGC，其中 45 个带官方配图），支持搜索，可一键"📍 在星图中居中定位"——星图平滑地把目标转到画面正中并放大，此刻在地平线下时自动跳到最佳观测月并提示 |
| 测验 | ① 认亮星：在真实星空图上点击目标星（按角距判分）；② 认星座：看图形选名称；③ 梅西耶：看类型/星座/星等信息猜编号。统计正确率与最高连对（localStorage 持久化） |
| 关于 | 使用说明、认星学习路线、数据与精度说明、图片来源与署名 |

## 数据来源与精度（截至 2026-10-04）

- 恒星：5044 颗至 6.5 等，J2000 坐标，源自 [d3-celestial](https://github.com/ofrohn/d3-celestial)（`stars.6.json`）；
- 星座：IAU 88 星座连线/边界/拉丁名（同上，`constellations*.json`），中文名已转简体核对；
- 梅西耶：110 个，坐标/星等与 `dsos.14.json` 交叉校准；M40（双星）与 M98/M102 用手工坐标；
- NGC：15 个著名天体，坐标/星等优先取自 `dsos.14.json`，NGC 4565 / NGC 2237 用手工坐标；
- 配图：45 张（30 梅西耶 + 15 NGC），来自 ESA/Hubble 与 NOIRLab 官方图库，CC BY 4.0；逐图 credit、许可与来源见 `assets/photos/CREDITS.md`；
- 行星：JPL 近似轨道根数（适用 1800–2050 年），误差通常 <1°；
- 月亮：低精度算法，误差约 1°，月相按照亮比例以半椭圆明暗界线绘制；
- 时间按北京时间（UTC+8）处理；未做章动/光行差修正（影响 <0.5°）。

## 重新生成数据

```bash
node gen/build.js
```

会重新读取 `_raw/` 并输出 `js/data-sky.js`（构建时会把 `gen/curated.js` 里手工整理的亮星吸附到星表精确坐标，并报告吸附失败/重复问题）。

更换或新增配图时（需要联网，只在准备素材时跑）：

```bash
node gen/fetch-photos.js          # 从 ESA/Hubble / NOIRLab 下载、转码、生成 js/photos.js 与 CREDITS.md
node gen/build.js                  # 更新数据与 index.html 里的 ?v=
```

`gen/fetch-photos.js` 支持只处理指定对象（例如 `node gen/fetch-photos.js M31 NGC 7000`），已有文件会跳过下载；连续失败 6 次会停止并列出失败项。

## 已知取舍

- 投影为**球极投影（stereographic，保角）**——与 Stellarium 默认投影同类，形状不失真；画布边缘到中心的放大率按 sec²(θ/2) 递增，故 1×（视场贴到 90° 半径）时边缘星点会显得稀疏属正常；滚轮缩放由牛顿法反解视角中心，使光标下的天体严格不动（实测误差 ≤0.01px）；
- 拖动为**方位-高度（"转头"）模型，屏幕滚转恒为 0**：左右拖＝转方位角、上下拖＝抬降视角；按住时抓到的那个天区被**解算式钉在光标上**（实测跟手误差 ≤0.5px），时间保持水平、画面永不倾斜；
- 视角高度角硬钳在 −80°…+89.6°：到天顶或天底就**彻底停住**（触界后只保留水平分量做绕天顶轴的方位旋转），结构上不可能翻到天顶另一侧——早期版本用"刚性旋转 + 事后钳高度角"，会先跨过天顶再把高度角改回来（方位角与滚转各翻 180°），后来又试过"限制旋转量"，仍会被"擦着天顶旁边过去"的弧线绕过；现模型已从构造上排除；
- 拖动、缩放、居中定位都保持 roll=0：连续大角度拖动不再累积倾斜（放弃"抓住星就整体刚性旋转"的手感，换取地平线永远水平、方向永远可预测）；
- 隐藏标签页中 `requestAnimationFrame` 会被暂停，已用 `setInterval` 兜底（后台约 1 fps 刷新）；
- 测验"认星座"包含全部 88 星座，部分暗弱星座难度较高属正常；
- 测验画布固定「天顶全景」（zoom 1、视角在天顶、正立，不受主星图视角影响）；星座小图用「以连线图形质心为中心的方位等距投影」，跨 0h（仙女座/飞马座）和近天极（小熊座）都不会再拉断、拉歪；
- 星座名落点取"该星座连线的图形质心"（`gen/build.js` 的 `bestLabel()`），不再用星表标注点——实测星表标注点有 32/88 个落在自身边界之外（金牛座偏 14.2°、天龙座 12.2°），会让名字离图形很远；
- 配图全部本地托管（`assets/photos` 约 29 MB，640/1280 WebP + JPEG 回退，懒加载），不直链 NASA/ESA 官网：官网改版或国内网络波动都会让页面出现破图；图下保留 credit 与许可链接；
- 深空编号在缩放 <1.7× 时隐藏（符号仍显示），否则全天视图里 125 个编号会糊成一片；放大后自动出现。
